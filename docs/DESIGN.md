# MMStudio 官网设计方案

## 1. 文档效力

本文档是 MMStudio 官网产品设计、视觉设计、内容规划和技术架构的唯一事实来源。开始任何实现工作之前，必须先更新本文档，再更新 `TODO.md`，最后才能修改代码或配置。范围或优先级发生变化时，同样先改本文档。

## 2. 项目标识

- 团队简称：**MMStudio**；英文全称：**MeaninglessMeaningStudio**（两款游戏站的页脚写作 Meaningless Meaning Studio）
- 中文名称：**待定**。「妄言真意」是暂用名，团队不满意，之后会更换；实现时中文名必须集中在 `src/i18n.ts`，不得散落在组件里。
- 游戏一：**积案拂尘 / Deadpan**，AI 悬疑盘问游戏，游戏站 <https://deadpan.hydroroll.team/>
- 游戏二：**海龟汤调查局**，情境推理游戏，游戏站 <https://hgt.mmstudio.games/>。官方英文名未确认，英文界面仍显示中文名，只用「Situation puzzles」作说明。
- 官网真实域名：**mmstudio.games**（海龟汤已运行在其子域名上）。仓库中现存的 `mmstdio.games` 是拼写错误，见第 12 节。
- GitHub 组织：<https://github.com/mmstudio-games>；官网仓库：<https://github.com/mmstudio-games/mmstudio>
- 没有正式 Logo，只能使用文字名称；不得制作、生成或使用替代 Logo。两款游戏的正式 Logo 也未提供，展示只用文字排版。

## 3. 本轮范围

用户要求：把整站重构成更高级、有设计感的网站，动态与交互更丰富，两款游戏都要展示，审美由设计方自行决定。参考来源为 designeer.xyz 收录的设计画廊（recent.design、Awwwards 等）及其中的站点（Lusion、basement.studio、Ragged Edge、Reboot、Astrodither、Annapurna Interactive 等）。

- **全站视觉与交互体系**（第 4 节）：暗色墨底、预加载、路由转场、自定义光标、磁吸按钮、胶片颗粒、平滑滚动。
- **工作室主页 `/`**（第 5 节）：完全重做。
- **全站框架**：页头、移动端菜单、页脚、预留页按新体系重做。
- **积案拂尘产品页 `/games/deadpan`**：第二轮按游戏本身的创意重做（第 6 节），原 3D 书按用户选择移除。第三轮按用户要求移除文字拖尾，光标与主页统一。
- **积案拂尘产品页第十轮（用户要求）**：「案卷总目」与「线索墙」合并成同一本会翻页的书「案卷册」（WebGL），参考 paper.design/mono 页面里的杂志（第 6.5 节）。章节顺序因此调整为 01 开卷（总目）→ 02 推理（线索墙）→ 03 盘问 → 04 见报。
- **积案拂尘产品页第十一轮（用户要求）**：书成为整页的核心。首屏调查桌与案卷册合并：打开页面就是一本合上的案卷册躺在积灰的桌上，拂尘、解开绕线扣后翻阅；总目、线索墙、盘问、见报、收尾都在书里依次翻到（第 6.6 节，取代 6.3 的区块划分）。
- 动态、团队资料、联系方式仍为预留页，不编造内容。

## 4. 全站视觉与交互体系

### 4.1 概念

两款游戏都是关于「提问—还原被隐去的真相」。全站的视觉隐喻是**一间暗室里的调查**：墨色桌面、手电光、档案纸、朱红批注、涂黑的机密条。「妄言」是表面的文字，「真意」藏在光照到的地方。

### 4.2 色彩（全站默认暗色）

- 墨底 `oklch(0.155 0.008 60)`（约 `#0d0b09`），卡面 `oklch(0.19 0.01 60)`
- 纸色前景 `oklch(0.92 0.025 85)`（约 `#ece3d0`），次要文字 `oklch(0.68 0.02 80)`
- 朱红强调 `oklch(0.6 0.19 33)`：批注、状态点、选区、光标标签
- 边框为纸色 14% 透明度
- 积案拂尘卡片沿用游戏站新闻纸与深褐色；海龟汤卡片沿用其站点主题色 `#f2efe6` 与墨色
- 保持直角，不使用圆角；状态点与光标也为方形

### 4.3 字体

- 标题：Playfair Display（拉丁）+ Noto Serif SC（中文，按 unicode-range 分片按需加载）
- 正文：Noto Sans
- 档案编号、HUD、标签：JetBrains Mono
- 红笔手写批注：Long Cang（中文）+ Caveat（拉丁），仅用于积案拂尘页首屏批注

### 4.4 动效与交互

- **平滑滚动**：全站一个 Lenis 实例，接入 GSAP ticker 与 ScrollTrigger。
- **预加载 · 暗室显影**（第七轮，用户看过原型后确认）：每个会话首次进入时显示。全站的「暗室」取其字面，冲洗照片的暗室，唯一的光是红色安全灯，红色由此而来，不再用横贯全屏的红色进度线。
  - 开场：黑屏顶部的红色安全灯闪两下亮起，照着一个显影盘，盘中泡着一张相纸。
  - 进度：相纸上的「MM STUDIO」字标与标语在药水中不均匀地一块块浮现，由模糊到清晰、对比逐渐升高，药水晃动带来轻微波纹，相纸表面有流动的液面反光。显影程度即进度；左下角写「暗室 · 显影中」，右下角是小号「显影」计数。
  - 定影：到 100 时安全灯熄灭、房间灯亮起，相纸变回真实的暖白色、字迹定影。
  - 停住等待点击（第九轮，用户要求）：定影后不自动进站，画面停住。相纸下方出现「点击进入 / Click to enter」（触屏为「轻触进入 / Tap to enter」），带缓慢呼吸的提示点，液面反光偶尔掠过。整屏都可点击，也可用回车或空格。加载页此时是一个获得焦点、带说明文字的按钮，读屏可以读到并操作。定影前的点击不响应。
  - 进站：点击后幕布带弧形上拉，露出首页，首页首屏入场同时开始。
  - 不使用首页首屏的「妄言 / 真意」、机密条、红笔划线，避免与其他段落撞款。等字体就绪后才关灯定影，全程约 3 秒。
- **路由转场**：切换页面时，墨色幕布带目的地名称自下而上揭开新页面。
- **自定义光标**：仅在精确指针设备上显示，为直角准星。跟随小方点；悬停链接变成四角取景框；悬停带标签的区域变成朱红方块并显示文字（如「打开卷宗」）。只在首屏隐藏系统光标（光束即光标）。
- **磁吸按钮**：主要按钮随指针轻微偏移，离开时弹回。
- **文字滚动悬停**：导航链接悬停时文字逐字上滚替换。
- **解码文字**：等宽标签进入视口或悬停时，逐字乱码后落定。
- **机密条**：涂黑条在滚动到位或悬停时收起，露出文字。
- **胶片颗粒**：全屏极淡的动态噪点。
- **页头**：向下滚动隐藏，向上滚动出现；顶部有朱红滚动进度线。
- 所有动效必须尊重 `prefers-reduced-motion`：关闭 Lenis、预加载、转场、光标、磁吸与滚动绑定动画，内容直接以最终状态显示。

## 5. 工作室主页 `/`

自上而下五段，随后是页脚。

### 5.1 首屏：手电

- 满屏暗室，页头叠在上方。
- 巨大标题「妄言」（英文 MEANINGLESS）。指针是一束手电光：光圈内，表层文字消失，露出同位置的朱红「真意」（英文为 MEANING，后面的 LESS 被划掉），以及散落的调查批注：两宗案件编号与状态、「MEANINGFUL CHOICES.」、红笔圈注。
- 光束中漂浮灰尘（Canvas 2D 粒子，离光越近越亮），呼应「拂尘」。
- 按下指针时光圈放大；闲置或触屏无操作时光束自动缓慢游走。
- 底部：一句定位、光束坐标 HUD、滚动提示。
- 滚动离开时标题上移变淡。
- 读屏只读到一个语义标题和定位语，视觉层对读屏隐藏。

### 5.2 关于提问

吸顶段落，滚动时逐字点亮；关键词先被机密条盖住，读到时揭开。文案（新写，基于两款游戏已公开的玩法，待用户审阅）：

- 中：两款游戏，同一个动作：提问。在《积案拂尘》里，你用自己的话盘问嫌疑人；在《海龟汤调查局》里，你只能问「是」或「不是」。言辞可以是妄言，选择却有真意。
- 英：Two games. One act: asking. In Deadpan, you question suspects in your own words. In 海龟汤调查局, you may only ask what can be answered yes or no. Words may be meaningless. Choices never are.

### 5.3 在办案件

两张吸顶叠放的案件卡，后一张滑上来时前一张缩小变暗。

- **CASE 001 积案拂尘**：深褐新闻纸底。左侧是随指针三维倾斜的卷宗封面，「机密」印章在进入视口时盖下；右侧是名称、介绍、三项特点（机密条揭开）、开发状态、「进入游戏」与「查看产品页」。（曾误改为卷宗抽屉，已按用户要求撤回；抽屉代码已按用户要求删除。）封面上的字号和位置随封面宽度缩放（容器查询 `cqw`，第九轮修复）：竖排「积案拂尘」始终保持一列，不与 ACTIVE ARCHIVE 相碰；竖排 DEADPAN 始终在纸面以内。
- **CASE 002 海龟汤调查局**：海龟汤站的米白纸底。一侧是翻牌板：示例问题「他是自杀的吗？」，下方翻牌依次显示主持人砚只会给出的四种回答：是 / 不是 / 无关 / 是，也不是（均取自海龟汤「关于」页）。另一侧是名称、介绍、三项特点、状态「凭邀请入座」、「进入海龟汤」。
- 不展示任何汤友原创题目或汤底。

### 5.4 设计札记

三条大号横排条目（沿用现有设计札记文案）。悬停时纸色从下向上填满该行，文字反色，编号解码。

### 5.5 最新讯号

一条随滚动速度加速、倾斜的巨型跑马灯，之后是日期、标题、正文与「关注开发进展」。

### 5.6 页脚

- 内容上滑后从下方露出页脚。
- 标语、站内与外部链接、语言切换、回到顶部。
- 占满宽度的「MMSTUDIO」字标，字母随滚动升起；指针靠近的字母变粗。字标与页面底边留出与左右页边距相同的间距，不贴底。

## 6. 积案拂尘页：一宗积案，从落灰到见报

### 6.1 出发点：游戏本身的创意

游戏站是一份民间旧案复核的报纸《奇案特刊》（英文版为 The Unfinished Record）。玩家的循环是：**在案卷总目里挑一宗积案 → 读开卷材料 → 用自己的话盘问在案人物 → 提交结论接受复核 → 案件以独家报道的形式见报**。报道分为导语、人物、裂痕、调查、结论、后事六节。

产品页就按这个循环讲，让访客亲手做一遍：拂去灰尘、开卷、提问、连线、见报。名字「积案拂尘」本身就是首屏的交互。

### 6.2 光标

与工作室主页统一，只用全站的方形准星光标（第 4.4 节）：跟随小方点，悬停链接变取景框，带标签的区域显示朱红标签（线索卡「拖动」、收尾「进入游戏」）。首屏封面与主页手电首屏一样隐藏系统光标，由准星小方点标出拂尘的位置。不另做拂尘框，不做文字拖尾（第三轮按用户要求移除）。

### 6.3 区块

> 第十一轮起，宽屏下这些区块全部并入案卷册的跨页，见 6.6；下表仍是窄屏、减少动态效果、无 WebGL 时的降级版本，也是各区块内容的来源。

| 序 | 区块 | 内容与交互 |
| --- | --- | --- |
| 0 | 积尘（首屏） | 一张积了灰的调查桌，详见 6.3.1。指针就是拂尘，拂去约四成后余灰自动散去；入场自动拂一笔作提示，触屏自动拂几笔后散去。 |
| 1 | 开卷 · 案卷册（01 开卷 + 02 推理） | 同一本书，详见 6.5。前半是**案卷总目**：游戏站编辑部卷宗的真实案名、案型、难度，中文版（江城）与英文版（Bramwick）并列，可按案型筛选，每行链接到游戏站案卷总目。后半是**线索墙**：嫌疑人、调查角色、矛盾的口供、遗漏的细节、时代的褶皱、真相六张卡，用朱红线相连，卡片可拖动，线实时跟随并带下垂。配「每一案都是新案」「非线性推理」。 |

#### 6.3.1 首屏：调查桌

第四轮重做。参考 Detective Box（撕边纸、红笔批注、打字机字）与可点击物件即导航的桌面场景。灰尘下不再是一张平铺的封面，而是一整张调查桌，桌上的物件就是这一页的目录。

- **桌面**：深褐皮面台垫，程序生成的纹理与咖啡杯印。灰尘铺满整张桌面。
- **案卷夹**（最大，居中偏左）：牛皮纸卷宗夹，右上角卷宗标签「CASE 001」，绕线扣封口，白色标签贴写「积案拂尘 / DEADPAN」、江城旧案复核室、CASE FILE 001—2026，盖「机密」章。点击后封面沿左边三维翻开，内页是「开卷目录」：定位、介绍、三项特点（红笔逐项打勾）、开发状态、「进入游戏」「向下阅读」；再点合上。
- **剪报**（右上）：撕边的《奇案特刊》剪报，头条「旧案重启，真相必达。」与正文，回形针夹着。点击滚到「见报」。
- **索引卡**（右下）：图书馆式横线索引卡，打字机字列出「案卷总目」前五宗案名与案型，其中一宗被红笔划线。点击滚到「开卷 · 案卷总目」。
- **讯问笔录便签**（左下）：螺旋装订便签，写着「问：」和「没有标准问句」。点击滚到「盘问」。
- **证物牌**（左上）：牛皮纸吊牌，写着三条线索，一根红线连到案卷夹的扣子上。点击滚到「推理」。
- **红笔批注**：拂尘完成后，手写体的红笔批注逐条画出（圈、箭头、章节号），如「01 开卷」「02 推理」「03 盘问」「04 见报」（第十轮起推理在盘问之前），指向对应物件，构成一份手写目录。
- **交互**：拂尘完成后，物件随指针做分层视差；悬停的物件抬起、阴影加深，光标显示章节名标签；拂尘完成前物件不响应点击，键盘聚焦任一物件会直接散尽灰尘。
- **左右推拉转场**（第六轮，用户确认）：点物件不再竖向滚动，而是镜头在桌面上平移。点中的物件先被拿起（抬高、转正），然后向右飞出画面，整张桌子同时向左滑走；一张纸色转场幕从右侧推入，上面用红笔手写章节名（如「02 盘问」），下面一笔划线。幕布盖满画面时页面瞬间跳到目标章节，再向左退出，目标章节从右侧轻推入位。案卷夹内页的「向下阅读」走同一转场。之后左下角出现「← 回到桌面」，点击后反方向推回首屏；首屏重新进入视口时隐藏。转场后焦点移到目标章节标题。页面阅读仍是竖向滚动，不做整页横向排布。减少动态效果时不播放推拉，直接跳转。
- **窄屏**：只保留案卷夹、剪报、索引卡，隐藏便签、证物牌与批注，关闭视差。
- **减少动态效果**：无灰尘，批注直接显示，无视差；案卷夹仍可开合。
- 所有文字取自已有文案与游戏站已确认内容，不新增产品信息。

**质感（第五轮）**：用户反馈物件太简单、缺少真实质感，尤其是案卷夹。

- **材质**：ambientCG 的 CC0 扫描材质。台垫用皮革（Leather030），案卷夹用卡纸（Cardboard002），证物牌用牛皮纸（Paper004），剪报用揉皱的纸（Paper003）并调成新闻纸色，标签贴、索引卡、便签、内页用细纹白纸（Paper001）并按物件调色。均转为 WebP，只在积案拂尘页加载。
- **光与影**：桌面上方一盏暖色台灯，所有物件朝灯一侧偏亮、背灯一侧偏暗。每件物件两层阴影，一层是贴地的紧实接触影，一层是柔和的环境影，影子方向由物件相对灯的位置算出。灰尘散开后，灯光随指针缓慢移动，影子与高光随之转向。
- **磨损**：纸边用 SVG 位移滤镜做毛边；卷宗夹有折角、压痕和手摸发暗的边；标签贴一角翘起、胶边发黄；剪报有对折折痕；索引卡一角折起。
- **油墨**：印章用 SVG 噪声滤镜做缺墨与斑驳；打字机字逐字浓淡与位置略有差异；手写字有笔压变化。
- **案卷夹结构**：双层卷宗夹，后片比前片高一截、标签长在后片上；开口一侧露出三张参差的内页纸边，其中一张夹着回形针；封面边缘有厚度与高光，沿书脊有一道压线；绕线扣为金属垫片加纸垫，红线实绕多圈并带阴影、留一截线头；翻开时封面分为靠书脊与外侧两段，外段先滞后弯起、再追上拉直，像卡纸一样有弯曲；节奏为「掀起一点→加速翻过→落桌轻弹」，合上时反向；两段各自按角度变暗，翻开平放后在桌上投下影子。开合全过程案卷夹保持在最上层，合上动画结束后才回落，避免红笔批注等压在摆动中的封面上。（第八轮，用户反馈翻页发死、合上时「03 推理」先盖上来）

### 6.4 视觉

沿用游戏站的材质：做旧新闻纸、墨色、朱红印章与双线分栏。

- 桌面暗色底：`#1b140d`，中心带暖色径向光（通过 `html[data-stage='deadpan']` 切换暖褐令牌）
- 新闻纸：`#e6cfaa`、`#f7efdc`，边缘 `#d7b98a`；墨色：`#17120d`；朱红：`#842219`
- 灰尘程序生成。纸、卡纸、皮革的底纹使用 CC0 扫描材质（用户已同意，第五轮起），来源与许可记录在 `src/assets/textures/README.md`；仍不使用游戏站的报头字体与头条图。

### 6.5 案卷册：案卷总目与线索墙合订成一本书（第十轮）

**出发点**：用户看了 paper.design/mono，要把「线索墙」（用户所说的「板子」）和「案卷总目」都做成那种书。该页首屏之下有一本竖放的杂志：WebGL 渲染，纸页是贴图；翻页时纸页沿书脊卷起弯曲，顶部露出一叠参差的纸边，页面带轻微高光与明暗；页面内容预先绘制成图，窄屏改用静态图。本项目沿用这些手法，但页面内容、配色与交互取自积案拂尘的材质与文案，不照搬其素材。

**结构**：一本书，同一个组件贯穿两个章节。书的状态由滚动驱动，页面内的章节标题（`dp-catalog-title`、`dp-board-title`）以读屏可读的标题放在书里，章节跳转按书页位置滚动。

- 书页（4 张纸，8 个面）：
  - 封面（牛皮纸硬壳）：贴标签「案卷总目 · 线索墙」、江城旧案复核室、CASE FILE 001—2026、书脊红布条、「机密」章。比内页大一圈，翻开后露出边框。
  - 跨页 1：左为封里的**总目序页**（标题「案卷总目」、说明、案型筛选标签、两版说明与总数），右为总目第 1 页。
  - 跨页 2：总目第 2、3 页。每页最多五宗，按当前筛选顺排；第 3 页末尾是「查看全部案卷 ↗」。
  - 跨页 3：**线索墙**，左右两页是黑色相册卡纸（暗褐色，带点阵与相册角贴），摊平后卡片与红线叠在整个跨页上。
  - 封底为硬壳，只在跨页 3 露出边框。
- 总目页面的行样式：编号（等宽、朱红）、案名（中文版用思源宋体系，英文版用标题字体）、案型章（朱红方框）、难度方格、版别小字，行间细线。悬停某行：整行底色加深、案名右移，光标显示「开卷」，点击在新标签页打开游戏站案卷总目。筛选标签在序页，点击后总目重新排版。取代原来的跟随指针小卡与行内展开。
- **翻页方式**：
  - 滚动驱动：本区块是一个高度约 `1 + 3×0.85` 屏的区域，里面一屏高的舞台吸顶（`position: sticky`），滚动进度换算成书页进度（`q` 从 0 到 3.4）。第 i 次翻页对应 `q ∈ [i+0.1, i+0.7]`，其余为停留。到跨页 3 后还有一段停留，之后书随区块滚出。
  - 页码控制：舞台底部「上一页 / 下一页」按钮与页码「01 / 04」，键盘左右方向键（焦点在舞台内）同样可翻；都是滚动到对应位置，不另存状态。
  - 章节跳转：桌面上的索引卡到跨页 1，证物牌直接到跨页 3；转场幕盖住画面时书直接就位，不播放翻页。
- **纸页弯曲**：每张纸是一个沿宽度细分的网格，绕书脊旋转，各顶点的角度沿纸面渐变，自由边滞后，翻动中间弯曲最大，起止时摊平；下角略滞后以带出卷角。由 CPU 逐帧更新顶点与法线。纸张之间保持几像素间距防止深度冲突。
- **厚度**：左右各有一叠纸边（带层线贴图的方块），随已落定的张数增减厚度；翻到半空的那张不计入任何一侧。方块只当背景绘制（不写深度、先于纸页渲染），所以不会盖住纸页。书整体向观众前倾约 15°，使顶部露出纸边；镜头焦距较长（视场角 16°），翻页时纸页冲向镜头的放大保持在约 1.15 倍。跨页 3 停下时书摊平到正对镜头，1 个世界单位恰好等于 1 个 CSS 像素，DOM 叠层与书页精确对齐。书的尺寸：一页宽取舞台宽的 45% 与舞台高 72% 折算值中较小者。
- **光与影**：一盏柔和的主光与环境光；纸页烘进书脊暗部与四边渐暗；弯曲产生的明暗来自真实法线。不用阴影贴图。
- **点击与悬停**：用射线命中纸页后读 uv，在该页的点击区域表里查找（案卷行、筛选标签、「查看全部案卷」）；书翻页途中不响应。悬停的行整行底色加深并左侧出朱红竖线，光标显示「开卷」「按案型筛选」「查看全部案卷」。行内的版别只写短名（江城 / Bramwick），完整说明在序页图例。
- **贴图**：页面内容用 Canvas 2D 绘制（字体沿用 Noto Serif SC、Playfair Display、JetBrains Mono，质感沿用 `fine-paper`、`folder-cardboard` 两张 CC0 材质），语言切换、筛选与悬停变化时只重绘受影响的面。贴图宽度约 800 px，并生成 mipmap 与各向异性过滤。
- **线索墙叠层**：跨页 3 停稳后，原有的 DOM 线索卡与 SVG 红线叠在书上，位置、拖动、方向键移动、线实时跟随带下垂、进入时线逐条画出，全部沿用 `deadpan-board` 的逻辑（抽成可复用的 `ClueWall`，书与降级版共用）。卡片只在书停在跨页 3 时可操作，翻页时淡出。
- **渲染成本**：Canvas 使用按需渲染（`frameloop="demand"`），只在翻页、悬停、重绘、缩放时出帧；书整体按需加载（动态导入），不拖慢其他页面。像素比上限 2。
- **交互提示**：区块首屏显示「向下滚动翻页」，翻到跨页 3 后换成线索墙的「拖动卡片，线会跟着走」。

**降级**：书是增强，不是必需。以下情形回到原来的两段 DOM 版本（案卷总目列表 + 线索墙），章节顺序与编号不变：

- 视口窄于 900 px 或矮于 560 px（包含手机）；
- 开启减少动态效果；
- 浏览器无法创建 WebGL 上下文，或书的代码加载失败。

读屏与键盘：书里始终有一份真实的 DOM 案卷列表（链接）、筛选按钮与线索墙标题，读屏可读、键盘可达；聚焦某宗案卷时书自动翻到对应跨页并高亮该行。书内可视元素对读屏隐藏，避免重复朗读。

**章节编号**：01 开卷（案卷总目）、02 推理（线索墙）、03 盘问、04 见报。首屏批注与物件标签、各区块抬头同步调整。

**不做**：不拖拽翻页（用滚动与按钮）；不在书里放盘问表单；不使用 paper.design 的任何图片、字体文件或页面设计，只借鉴「会翻页的书」这一做法。

### 6.6 整页是一本书（第十一轮）

> 本节的镜头设计取代 6.5 中「一页宽取舞台宽的 45% 与舞台高 72% 折算值中较小者」的固定尺寸；书在世界里仍是固定大小，由镜头距离与取景决定它在画面里的大小。

**用户要求**：首屏的调查桌与案件总览合并，打开就是一本书；书是整页的核心；后面的部分随之调整得更和谐。用户确认：整页都是书；桌面物件变成书里夹的东西、导航改用索引标签；先拂尘、再解开绕线扣。

**总体**：宽屏下积案拂尘页只有一个吸顶的舞台，背景是同一张皮革桌面与台灯光，从头到尾不换；往下滚就是翻阅这本案卷册。页面里不再有「大标题加一块内容」的网页式区块，所有标题印在书页上，页边只留统一的小标签与 HUD。

**首屏（跨页 0）**
- 画面：桌面中央一本合上的案卷册，蒙着灰；书右缘伸出四枚索引标签（01 开卷、02 推理、03 盘问、04 见报）；铅笔、咖啡杯印留在桌上作氛围。原来的证物牌、剪报、索引卡、便签不再是桌面入口：证物牌的三条线索并入推理卷首，剪报并入见报页，索引卡并入总目，便签并入盘问页。
- 红笔批注沿用原来的手写目录，改为指向索引标签，拂尘完成后逐条画出；章节号与名称同步为 01 开卷 / 02 推理 / 03 盘问 / 04 见报。
- 拂尘：指针就是拂尘，灰尘盖住整张桌面与书；拂去约四成后余灰散去（沿用现有机制，含自动拂一笔、触屏自动拂、键盘聚焦即散尽）。灰尘散去前，向下滚动或点任意位置同样会让余灰散去。
- 解扣：灰尘散去后封面的绕线扣可以点（带「解开」光标标签与轻微晃动提示）；解开后红线松落，封面掀开，书被带到跨页 1。灰尘散去后直接向下滚动，等同于解扣。
- 合上的书整体位于舞台中央偏左，翻开后居中；封面用现有案卷夹的材质与「机密」章，调查桌里不再出现第二个「案卷」。

**镜头：书不再一直待在画面中央的小块区域**（用户看参考站后指出「只有一本书容易显得空」，第十一轮追加）
- 滚动同时驱动镜头推拉，一共四种取景：
  - 全景：开场与收尾。整张桌子入画，书约占画面高的 55%，四周的桌面物件完整可见。
  - 推近：翻开后到总目。一页宽取舞台宽的 45% 增至约 48%，高度超出舞台时顶部与底部被裁，页面几乎铺满屏幕，一行案名读起来像近景。镜头沿书脊略偏移，看向当前活动的那一页。
  - 正对：线索墙、盘问。书摊平，镜头正对，1 世界单位 = 1 CSS 像素，DOM 叠层精确对齐。
  - 拉升：见报。头版纸页升起朝向镜头，报头与头条「旧案重启，真相必达。」占满视野。
- 取景之间连续过渡，不硬切；鼠标位置带动镜头做 ±2° 内的视角偏移（触屏用自动缓慢游走）。
- 正对取景下镜头不偏移，叠层精度优先。

**桌面物件随章节更换**（书的两侧不再是固定的空白）
- 物件是普通网页元素（图片式的 CSS 绘制，沿用调查桌的材质与阴影做法），叠在书的画布之后或之前，按鼠标做分层视差；书的画布只有一个。
- 每个跨页的两侧各放 2 到 3 件，随跨页滑入、滑出，内容只用已确认的文案：
  - 总目（跨页 1–3）：索引卡盒、放大镜；悬停某宗案卷时，一张小卷宗卡从页面「抽」到桌上（取代原来跟随指针的小卡）。
  - 推理（跨页 4）：红线从书页边缘继续拉到桌上的证物牌与图钉；证物牌写着三条线索。线索卡可以拖出书外，拖到桌面上也保留红线（页面外区域按桌面坐标记，不影响书页对齐）。
  - 盘问（跨页 5）：打字机或速记本；访客输入时，旁边的纸条逐字「打」出来。
  - 见报（跨页 6）：一叠《奇案特刊》，最上面一份与书里的头版同款。
  - 开场与收尾（全景）：铅笔、咖啡杯印、证物牌、剪报、索引卡、便签全部出现，等于原来调查桌的物件回到桌面上，只是不再承担导航（导航是索引标签）。
- 窄屏、减少动态效果、无 WebGL：不显示这些物件，沿用原调查桌。

**红笔批注与灰尘痕迹是活的**
- 红笔批注不只出现在首屏：每个跨页，书旁的桌面上有几笔红笔随滚动写出、画圈、画箭头；悬停某宗案卷时，红笔在书页上圈住该案名（画在页面贴图上，随悬停变化）。
- 拂尘擦过的痕迹保留：擦过的地方干净，桌面边角与书未擦到的边缘仍蒙一层薄灰；灰层只在首屏消散，之后以静态的薄灰贴图留在桌面边缘，不再占用逐帧渲染。
- 手写体沿用 Long Cang 与 Caveat，仅用于批注。

**阶段一实现中的取值**（与上文取景描述对应；真机调整时以这里为准）
- 取景缩放：全景 0.9、推近 1.06、正对 1.0（书在世界里大小固定，整体缩放即推拉镜头）；一页宽取舞台宽 45% 与舞台高 72% 折算值中较小者。推近取 1.06 而非更大，是为了不压住页顶的章节标签行。
- 鼠标视角偏移：绕 y 轴 ±0.05 rad、绕 x 轴 ±0.035 rad；正对取景时为 0。
- 索引标签画在纸页自由边外多出的 38 单位宽的一条上（封面尺寸的面没有），随纸页一起弯曲；点击区域按贴图坐标命中，透明的标签区让射线穿过去。阶段一里 03 盘问、04 见报两枚标签点击后滚到下方原有的盘问、见报区块。
- 桌面物件：合上时（全景）显示证物牌、剪报、索引卡、便签；推近的总目跨页换成索引卡盒、放大镜；线索墙跨页换成证物牌与红线、两枚图钉。红铅笔与咖啡杯印常在。
- 线索卡暂时仍只能在书页范围内拖动；拖出书外留在阶段二评估。

**阶段二实现中的取值**
- 书共 7 张纸、8 个跨页（0 合上、1 开卷目录、2–3 总目、4 线索墙、5 盘问、6 见报、7 收尾）。第 6 张纸翻完后（`q ≥ 6.2`）整本书合上：各页自上而下错开 0.03 依次落回右侧，约在 `q = 6.85` 合拢；封面最后落下，书回到画面中央，镜头拉回全景（缩放 0.9），桌上所有物件重新出现。
- 盘问：左页是说明页（标题、说明、「进入游戏」），右页是画好横线的讯问笔录，问题与输入框由网页叠层写在上面（`AskRecord`，容器宽度即一页宽，内部尺寸按 512 单位换算）；叠层只在书停稳于跨页 5 时可聚焦。回答栏的机密条沿用原组件。
- 见报：同一张《奇案特刊》头版横跨左右两页，报头压过书脊；头条在逗号处断行；右页有引文、六节目录、信号与「关注开发进展」链接。头版在书里是静态印刷，只有「已刊」章作为网页叠层在停稳后盖下（缩放 1.1，位置按整幅跨页比例）。
- 收尾：书合上后，左侧一句「案卷未封，调查员仍在。」，右侧巨大的「开卷」链接与「查看全部案卷」；叠层只在跨页 7 停稳后可点。点封面绕线扣会回到开卷目录。
- 取景：见报时缩放 1.1（线索墙与盘问为 1.0，叠层精确对齐）；合上时缩放与偏移随各页的角度连续回到全景。
- 桌面物件：盘问章换成速记本（便签）与墨水瓶，见报章换成一叠《奇案特刊》。
- 每个跨页书旁有一笔红笔批注（文字取自已有文案：开卷目录、全部 · 14、查看全部案卷、拖动、向在案人物提问、已刊）；悬停某宗案卷时，红笔在书页上圈住案名。

**导航**
- 索引标签：贴在书的右缘（翻到左边后跟着纸页到左缘），点标签翻到对应章节的第一个跨页；当前章节的标签凸出得更多。
- 页脚 HUD 与键盘（上一页 / 下一页、左右方向键）沿用第 6.5 节；页码改为「第 n / 8 跨页」。
- 取消左右推拉转场幕与「回到桌面」按钮：章节跳转、红笔批注、标签都是翻页；「回到桌面」由向上滚动或跨页 0 的标签承担。
- 每个跨页的顶部小标签显示章节号与名称（01 开卷 / 02 推理 / 03 盘问 / 04 见报），取代各区块自带的 SectionLabel。

**和谐**
- 桌面、台灯光、胶片颗粒、纸张色、朱红印章、手写批注在整页只有一套；盘问、见报、收尾不再各自有背景。

- 书页之间的叠层（线索墙、讯问笔录输入）只在书停稳并摊平时出现，翻页时淡出；其余时间书页是纯贴图。

## 7. 降级与无障碍

- 灰尘下的封面文字是真实 DOM 文字，灰尘 Canvas 对读屏隐藏。
- 开启减少动态效果时：不铺灰尘、不播放滚动绑定动画，内容直接完整显示；线索墙仍可拖动。
- 首屏粒子与灰尘离开视口或无内容时停止渲染。
- 线索卡可用键盘聚焦；拖动只是附加玩法，不承载信息。
- 画布与纯装饰层对读屏隐藏。导航、语言切换、跳至正文、章节跳转均可用键盘操作，焦点可见。
- 主页在窄屏上保持同样的叙事，手电改为触摸跟随与自动游走。

## 8. 技术架构

现有技术栈**只增不减**，升级版本与新增依赖均可，不得删除或替换现有技术。

- 保持不变：Bun、TypeScript、React、Vite、React Router、shadcn/ui（Sera，Base UI）、Tailwind CSS v4、Zustand、react-i18next、Biome、GitHub Actions CI、Cloudflare Workers
- 已新增：`three`、`@react-three/fiber`、`@types/three`（3D 渲染；第十轮起用于案卷册，见 6.5，只在积案拂尘页按需加载），`lenis`（平滑滚动）
- 本轮新增：`gsap`、`@gsap/react`（时间线与 ScrollTrigger）、`@fontsource-variable/noto-serif-sc`、`@fontsource-variable/jetbrains-mono`、`@fontsource/long-cang`、`@fontsource-variable/caveat`
- 滚动进度放在 ref 中传递，不放入 Zustand；Zustand 仍只保存语言偏好。预加载完成等一次性信号用模块级事件，不进 Zustand。

### 目录与命名

- 组件文件名 `kebab-case`；shadcn 基础组件只放 `src/components/ui`
- 通用动效组件放 `src/components/motion/`（光标、磁吸、解码文字、机密条、翻牌、跑马灯、颗粒、预加载、转场）
- 页头页脚放 `src/components/site/`，`site-layout.tsx` 负责组装
- 主页区块放 `src/components/home/`，积案拂尘页区块放 `src/components/deadpan/`；案卷册相关文件：`case-book.tsx`（区块、滚动映射、HUD、降级）、`case-book-scene.tsx`（r3f 场景，动态导入）、`book-pages.ts`（页面贴图绘制与点击区域）、`book-nav.ts`（滚动与书页位置换算，章节跳转共用）、`clue-wall.tsx`（线索卡与红线，书与降级版共用）
- 通用 hooks 放 `src/hooks/`，平滑滚动与动效工具放 `src/lib/`
- 页面放 `src/pages/`

### 样式规范

- 布局与样式优先用 Tailwind 工具类，直接写在 TSX 中，不得为普通布局建立业务选择器。
- `src/index.css` 只保留 Tailwind、字体、shadcn 语义令牌、动画关键帧和必要的全局规则。积案拂尘页通过 `html[data-stage='deadpan']` 覆盖语义令牌。
- 光束位置等高频变化值通过 CSS 变量写入，不经过 React 渲染。
